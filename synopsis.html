🌱 1. Introduction

Agriculture requires timely, data-backed decisions regarding crop selection and fertilizer application. Traditional recommendations often overlook soil micronutrient states and microclimatic parameters. Furthermore, existing machine learning recommendation models frequently output "black-box" predictions without transparent reasoning.

The Intelligent Crop and Fertilizer Recommendation System bridges this gap by uniting supervised classification, regression models, unsupervised anomaly detection, and Explainable AI (SHAP). By analyzing essential soil attributes (Nitrogen, Phosphorus, Potassium, pH, Organic Carbon) alongside climatic factors (temperature, humidity, rainfall), the system determines the optimal crop, prescribes fertilizer type and exact dosage (kg/acre), flags abnormal readings, and delivers feature importance explanations via an interactive Streamlit dashboard.

⚠️ 2. Problem Statement

Farmers face significant hurdles in selecting suitable crops and determining appropriate fertilizer doses tailored to field conditions. Current systems suffer from three major shortcomings:

  • Single-task silos: Systems handle crop selection or fertilizer recommendation independently without unified agronomic synergy.
  • Lack of interpretability: Machine learning models output results without explaining why a recommendation was made.
  • Sensor / reading anomalies: Sensor errors or erroneous lab reports lead to corrupted recommendations without automated validation.

🎯 3. Project Objectives

  • Develop a supervised multi-class classifier to recommend optimal crops based on soil and climate variables.
  • Construct a fertilizer classification model to predict fertilizer type and a regression model to estimate dosage (kg/acre).
  • Detect erroneous or anomalous soil test readings using unsupervised Isolation Forest.
  • Integrate Explainable AI (SHAP) to identify input feature contributions and build trust with end-users.
  • Perform automated nutrient-gap calculations and rule-based natural vs. chemical fertilizer allocation.
  • Provide interactive "What-If" scenario simulations and deployment via a clean Streamlit dashboard.

⚙️ 4. System Workflow & Methodology

  1. Data Acquisition: Manual parameter input or automated soil test report extraction via OCR.
  2. Preprocessing: Input sanitation, validation, normalization, and feature formatting.
  3. Anomaly Detection: Isolation Forest checks inputs for sensor corruption or out-of-distribution values.
  4. Crop Recommendation: Supervised classification algorithm predicts the highest-yielding crop.
  5. Nutrient Gap Analysis: Compares current soil N-P-K levels with target crop requirements.
  6. Fertilizer Classification: Classifies recommended fertilizer type (e.g., Urea, DAP, 10:26:26, Compost).
  7. Dosage Regression: Estimates required application quantity in kg/acre.
  8. Explainability Layer (SHAP): Calculates SHAP values displaying positive and negative feature contributions.
  9. Agronomic Allocation: Rule-based module splits natural organic vs. chemical fertilizer recommendations.
  10. What-If Scenario Simulator: Allows users to toggle sliders and observe real-time output shifts.
  11. Cost & Carbon Footprint: Evaluates ecological and financial implications across fertilizer options.
  12. Interactive Presentation: Delivers predictions, charts, and explanations through Streamlit.
